# Инженерный клуб — сайт с личным кабинетом

Проект: сайт образовательного курса для школьников 9–14 лет.
Сейчас это статический HTML/CSS/JS прототип (site.html) — кликабельный, 
но ничего не хранит по-настоящему (прогресс — в localStorage, оплата — демо).

Задача: превратить в рабочий сайт с личным кабинетом.

Стек, который используем:
- Backend/БД/авторизация — Supabase - зарегистрировался 
- Видеозвонок в уроке — Jitsi Meet (iframe)
- Оплата — ЮKassa (подключим позже, не сейчас)
- Хостинг фронтенда — GitHub Pages (репозиторий 79112686806-bot/79112686806-bot.github.io → https://79112686806-bot.github.io/, публикация через
  GitHub Actions). Vercel заменён: *.vercel.app в России без VPN не открывается.
- Отправка писем клиентам — через Supabase Auth (письмо с приглашением/установкой пароля при создании аккаунта после оплаты) или Resend из Edge Function, если понадобится более гибкий шаблон письма

Функциональность:
- После оплаты создаётся аккаунт ученика в Supabase, пароль или ссылка для его установки высылается клиенту на почту автоматически
- У создателя (администратора) есть возможность подтверждать пройденную учеником тему — после подтверждения ученику открывается доступ к следующему блоку курса в личном кабинете

Стиль: не переписывать дизайн и тексты без явной просьбы, 
менять только то, что относится к текущей задаче.
Все секретные ключи — только в .env, никогда не писать их в код напрямую.
